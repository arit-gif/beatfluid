# BeatFluid 🎶 — music that moves

A beat-reactive WebGPU fluid universe. Play YouTube playlists, sing karaoke,
raise a virtual pet, vibe with friends in Together Rooms — all inside living,
breathing color.

**Live demo:** `https://<your-username>.github.io/<repo>/` _(auto-deployed on every push to `main`)_

## ✨ Features

**🎵 Music**
- YouTube playlists (tabs, search, likes, history, shuffle, sleep timer, volume fade)
- 🎤 Karaoke with free synced lyrics · 🎙️ voice control · 🪟 pop-out mini player
- 📦 Offline Chill Pack — 3 original royalty-free tracks, generated by code
- True beat engine: BPM clock, mic-listen kick detection, or local-file FFT

**🐾 Pet 2.0**
- 3 hand-drawn CSS pets: evolving Bloop 🫧 → ✨ → 🌟 → 👑, plus Mishti 🐱 & Bhulu 🐶
- Draggable, wander mode, Tamagotchi hunger/fun/energy, beat-dancing, talking bubbles
- Favorite foods, tricks, bond hearts, dreams, daily streaks, hats, party + photo mode

**👯 Together Rooms** — no-login P2P listening parties: host DJ, vote-skip, queue, reactions

**🎪 Fun Zone** — toy piano, tap battle, shake-for-splash, festival packs (Puja 🥁/Diwali 🪔/Holi 🎨), auto day/night

## 🚀 Quick start

```bash
git clone https://github.com/<your-username>/<repo>.git
cd <repo>
npm install
npm run dev      # local dev server with hot reload
```

| Script            | What it does                              |
| ----------------- | ----------------------------------------- |
| `npm run dev`     | Start the dev server                      |
| `npm run build`   | Type-check + production build into `dist/` |
| `npm run preview` | Preview the production build locally      |

Requires **Node.js 20.19+ or 22+**.

## 🌐 Deploy

- **GitHub Pages (recommended):** push to `main` → the included workflow builds &
  publishes automatically. Just enable it once: repo **Settings → Pages → Source:
  GitHub Actions**.
- **Netlify:** drag-and-drop the `dist/` folder, or connect the repo (build command
  `npm run build`, publish directory `dist`). A ready `netlify.toml` is included.

The build uses relative asset paths (`base: "./"`), so it works under any
domain or sub-path with zero config.

## 🛠️ Tech stack

React 19 · TypeScript · Vite · WebGPU fluid simulation (`vgpu`, custom WGSL
shaders) · YouTube IFrame API · PeerJS (rooms) · Web Audio (beat analysis,
synth piano, pet sounds) · localStorage persistence — no backend, no database.
